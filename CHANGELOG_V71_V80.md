# PokeBot v71–v80 release ledger

Each version is represented in the consolidated v80 source tree. Database changes are delivered by migration `20260912_0009_v80_systems.py`.

| Version | Theme | Principal implementation |
|---|---|---|
| v71 | Collection UX | Search, detail, nicknames, favorites, profiles |
| v72 | Identity | Natures, abilities, gender, held items |
| v73 | Moves | Four slots, legal learning, PP persistence |
| v74 | Items | Healing, leveling, PP restoration, equipment |
| v75 | Completion | Pokédex entries and achievements |
| v76 | Auctions | Escrow, reserved bids, refunds, settlement |
| v77 | Social | Friend requests and friend lists |
| v78 | Seasons | Season XP and claim-once reward tiers |
| v79 | Reliability | Persistent idempotency for economic actions |
| v80 | Operations | Auto settlement, health, guide, tests, docs |

# PokeBot v65 Playtest Checklist

## Before inviting testers
- Confirm env vars are set
- Confirm API, bot, and workers start
- Confirm /playtest_status works
- Confirm /start_game and onboarding commands respond
- Confirm spawn, catch, battle, market, and event flows respond

## During playtest
- Log confusion points
- Log failed commands
- Log economy exploits
- Watch battle pacing
- Watch reward inflation
- Note where players stop engaging

## After playtest
- Review event counts
- Adjust balance knobs
- Clean up confusing outputs
- Patch abusive loops
- Repeat with another test round
